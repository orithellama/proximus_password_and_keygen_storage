# Interface and copy conventions

- Never use middle dots or bullet glyphs as text separators in the app, documentation, release notes, or marketing copy. Use an ordinary ASCII hyphen (`-`), for example `Solana - SOL`.
- Apply the same rule to sample data, screenshot captions, and generated previews. Recapture affected screenshots after changing interface copy.
- Preserve functional password masking, ordinary punctuation, decimal points, and mathematical notation.
